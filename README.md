
# Dental Clinic Management ERP

A full-stack Dental Clinic Management ERP developed as part of the AAHA Solution Software Developer Internship.

## Project Overview

This application is designed to manage the daily operations of a single dental clinic.

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Java 21
- Spring Boot
- Spring Security

### Database
- MySQL

## Planned Modules
- Authentication and User Management
- Doctor Management
- Patient Management
- Appointment Management
- Treatment Management
- Billing and Payments
- Reports and Analytics

## Architecture
- Modular Monolith
- Layered Architecture

## Development Status

Project setup and initial development are in progress.
